# 📘 MathCircle - E-Modul Materi Lingkaran Berbasis Model Discovery Learning

**MathCircle** adalah sebuah website e-modul interaktif berbasis HTML, CSS, dan JavaScript yang dikembangkan untuk membantu proses pembelajaran materi **lingkaran** di jenjang SMA. Modul ini dirancang agar mudah digunakan oleh guru maupun peserta didik secara mandiri, interaktif, dan menyenangkan.

🌐 **Live Demo**: [https://kaaisha.github.io/MathCircle/](https://kaaisha.github.io/MathCircle/)


## ✨ Fitur Utama

- 📚 **Materi**: Penjelasan konsep dasar lingkaran yang mudah dipahami.
- 📄 **LKPD**: Lembar kerja peserta didik menggunakan GeoGebra.
- 🎥 **Video Pembelajaran**: Disisipkan video sebagai penunjang materi.
- 📝 **Kuis Interaktif**: Soal pilihan ganda lengkap dengan skor dan pembahasan otomatis.
- 📱 **Responsif**: Bisa diakses lewat HP, tablet, maupun komputer.
  

## 🧑‍🏫 Sasaran Pengguna

- **Guru**: Sebagai media ajar dalam pembelajaran matematika di kelas.
- **Peserta Didik**: Sebagai sumber belajar mandiri untuk memperdalam materi.
